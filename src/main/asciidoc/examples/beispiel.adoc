== Einleitung

An der Fakultät für Informatik und Mathematik ist eine Neuentwicklung des bisherigen ZPA-Systems geplant.
Ziel ist es eine einheitliche und benutzerfreundliche Plattform zu entwickeln, die allen Beteiligten eine Erleichterung bewirkt.
Im bisherigen ZPA-System können sich Studierende für FWP-Fächer, praxisbegleitenden Unterricht, Praktikumsgruppen und Seminare eintragen.
Lehrkräfte nutzen es, um die Einteilung der Praktikumsgruppen abzurufen oder den Stundenplan anzuzeigen.
Das Dekanatsteam verschafft sich mithilfe des Systems einen Überblick über die Auslastung und Verteilung der Kursteilnehmer.
Admins haben die Möglichkeit, Kurse und Räume zu verwalten.

Da eine Anbindung weitere Systeme an das aktuelle System technisch nicht machbar erscheint, soll eine Neuentwicklung eine offenere Plattform für weitere Systeme schaffen.
Folgende Systeme sollen u.a. integriert werden:

* Primuss: hochschulweites System zur Verwaltung der Noten
* Moodle: hochschulweite Lernplattform

Zudem weist das aktuelle System zahlreiche Fehler auf und hält den Ansturm der Studierenden nicht immer statt.
Das System soll auch benutzerfreundlicher werden und eine moderne Benutzeroberfläche bekommen, die auf verschiedensten Plattformen nutzbar ist.
Zur Realisierung des Projekts steht ein Gesamtbudget von 250.000 € zur Verfügung.
Der Betrieb der Anwendung soll auf den Systemen des LRZ erfolgen.
Die Einführung des neuen ZPA Next Generation ist schrittweise in den nächsten 3 Jahren geplant.
Zunächst soll die Fächerauswahl umgesetzt werden, danach in mehreren Iterationen die nächst wichtigen Features.
Damit die Reihenfolge der Umsetzung sich an der Wichtigkeit der Features orientiert, soll im Projekt das Vorgehen Scrum angewendet werden.

== Rollen

Für das ZPA System sind die in den folgenden Abschnitten beschriebenen Rollen relevant.

=== Lehrkraft

Lehrkräfte interessieren sich für die Belegung Ihrer Kurse. Relevante Informationen sind die Auslastung der Praktikumsgruppen und die Daten der teilnehmenden Personen. Lehrkräfte haben weitreichende Administrationsrechte auf ihren Kursen und können Räume in der Hochschule buchen. Die Berechtigungen für Lehrkräfte werden für interne Fakultätsmitglieder und externe Personen (z.B. LBAs) unterschieden.

==== Standardablauf

1. Der Akteur öffnet die Raumbuchung.
2. Das System zeigt den Raumbuchungsdialog an.
3. Der Akteur wählt den gewünschten Zeitraum aus.
4. Das System zeigt alle am gewünschten Zeitraum verfügbaren Räume an, die zu den gewählten Raumparametern passen.
5. Der Akteur wählt den passenden Raum aus.
6. Das System erstellt eine neue Buchung, die den Raum für den Akteur reserviert.
7. Das System zeigt eine Bestätigungsseite mit den Buchungsdaten an.
Parallel dazu verschickt das System eine E-Mail mit den Buchungsdaten an den Akteur.
